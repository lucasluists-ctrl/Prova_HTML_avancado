# Prova_HTML_avancado

# 🎂 Site de Bolos

Este projeto foi desenvolvido como parte de uma **prova prática de HTML**, com o objetivo de aplicar os principais conceitos aprendidos durante as aulas.

O site possui como tema principal **bolos e confeitaria**, apresentando diferentes páginas interligadas através de um menu de navegação.

## 🍰 Sobre o projeto

O projeto foi desenvolvido utilizando apenas **HTML**, sem o uso de CSS ou JavaScript.

Durante o desenvolvimento foram utilizados diferentes elementos da linguagem HTML para organizar e apresentar o conteúdo do site de forma estruturada.

## 🛠️ Recursos utilizados

Durante o projeto foram utilizados:

- Tags semânticas do HTML;
- Formulários;
- Tabelas;
- Imagens;
- Áudio ou vídeo local;
- `figure` e `figcaption`;
- `details` e `summary`;
- Elementos de marcação de texto;
- Links para navegação entre páginas;
- Organização dos arquivos em pastas.

## 📁 Organização

O projeto foi organizado utilizando pastas separadas para os diferentes tipos de arquivos:

- `HTML/` — páginas do site;
- `IMG/` — imagens utilizadas;
- `GIF/` - gifs;
- `audio/` — arquivos de áudio;
- `video/` — arquivos de vídeo.
