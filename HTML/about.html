︶⊹ Sobre o Site 🎂 ⊹︶

Este site foi desenvolvido como parte de uma prova prática de HTML, com o objetivo de aplicar os conhecimentos aprendidos durante as aulas.

“HTML é uma linguagem de marcação utilizada para estruturar o conteúdo de uma página.”

Conceito apresentado pelo professor durante as aulas.

O tema escolhido foi bolos e confeitaria. A proposta do site é reunir conteúdos relacionados ao tema de uma maneira simples e divertida, incluindo receitas, imagens, músicas e curiosidades.

︶⊹ Objetivo do projeto

O principal objetivo deste projeto é demonstrar diferentes recursos disponíveis no HTML através da criação de páginas conectadas entre si.

Durante o desenvolvimento foram utilizados elementos como formulários, tabelas, imagens, vídeos, áudios, listas e diferentes tipos de marcação de texto.

︶⊹ Como o site foi desenvolvido?

Todo o site foi construído utilizando apenas HTML, sem a utilização de CSS ou JavaScript.

Os arquivos foram separados em pastas para manter o projeto organizado, dividindo as páginas HTML, imagens, GIFs, áudios e vídeos.

organização do projeto
  • HTML — páginas do site
  • IMG — imagens utilizadas
  • GIF — banners e animações
  • AUDIO — arquivos de áudio
  • VIDEO — arquivos de vídeo
